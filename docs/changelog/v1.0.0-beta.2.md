## ⚡ 破坏性变更

- **插件 `_ui_schema.json` 格式升级**：新增 `composite`、`form`、`playlist` 类型，`columns[].type` 扩展为 `badge | link | switch | text | number | date | image`

## ✨ 新增功能

### 插件声明式 Web UI 系统

插件通过 `_ui_schema.json` 纯 JSON 声明前端界面，**无需手写 HTML/CSS**。宿主应用（`PluginUI.tsx`）统一渲染，自动继承主题。

#### 7 种页面类型

| 类型 | 说明 |
|------|------|
| `stats` | 统计卡片（支持 `subtitle`、`format: "duration"`） |
| `table` | 数据表格（8 种列渲染类型） |
| `list` | 行列表（内联操作） |
| `cards` | 卡片网格（1-2 列响应式） |
| `playlist` | 完整点播单（房间选择器 + 统计栏 + 批量操作 + 状态切换） |
| `form` | 表单构造器（7 种表单控件） |
| `composite` | 复合页面（多类型 section 组合） |

#### 8 种列渲染类型

| `type` | 渲染 |
|--------|------|
| `badge` | 彩色圆角徽章，自动检测状态关键词着色 |
| `link` | 可点击链接，支持 `href_template: "https://example.com/{id}"` |
| `switch` | 行内 toggle 开关，通过 `switch_url` 自动 POST |
| `text` | 可换行文本 |
| `number` | 格式化数字，`decimals` 控制精度 |
| `date` | 格式化日期/相对时间（`"刚刚"`、`"3分钟前"`、`"2天前"`） |
| `image` | 图片缩略图，`image_width` 控制尺寸 |
| *(无)* | 纯文本 |

#### 操作模式

| 模式 | 说明 |
|------|------|
| `prompt_field` | 弹出输入对话框，收集数据后 POST JSON body |
| `prompt_field.input_type: "select"` | 下拉选择器 |
| `body_template` | 从行数据构建请求体：`{"action": "{{row.name}}"}` |
| `show_when` | 条件显示按钮 |

#### 表单构造器

支持 7 种表单控件：`text`、`password`、`number`、`date`、`textarea`、`select`、`switch`，带 `required` 验证和 `default` 默认值。

### PluginDataManager — 插件数据沙箱

新增 `core.plugin.data_manager.PluginDataManager` 类，通过 `self.data` 属性注入插件实例：

| 方法 | 说明 |
|------|------|
| `read_json(filename)` | 读 JSON，不存在返回 `None` |
| `write_json(filename, data)` | 写 JSON（自动创建目录） |
| `read_text(filename)` | 读纯文本 |
| `write_text(filename, content)` | 写纯文本 |
| `delete(filename)` | 删除文件/目录 |
| `exists(filename)` | 检查路径 |

所有路径强制限定在插件数据目录内——`../` 逃逸和绝对路径均抛出 `ValueError`。

### 多直播间点播系统（song_request）

- 按 `room_id` 隔离的多直播间点播单
- `/rooms` 端点自动发现直播间（优先 Server 已连接的，补充事件中见过的，兜底持久化数据）
- 房间选择器下拉切换
- 批量状态操作 + 批量删除
- 清空点播单按钮（`ConfirmDialog` 二次确认）
- 批量工具栏固定底部，不挤压列表项
- 状态变更同步通知到直播间

### ConfirmDialog 通用确认对话框

`web/frontend/src/components/ConfirmDialog.tsx` — 项目级可复用组件，支持 `danger` 模式、`loading` 状态。

### 插件失败处理增强

- 重试逻辑：移除旧条目 → 重新加载 → 重新激活（若 `initialize()` 失败则重试失败）
- 放弃加载：回退到禁用状态，保留元数据和目录文件
- 前端失败列表自动刷新

## 🐛 Bug 修复

### P0 级别
- **`enable_plugin` 初始化失败后仍标记 `enabled=True`**：`_activate_plugin` 现在在 `initialize()` 失败时抛出 `CorePluginLoadException`，阻止状态被错误覆盖
- **`disable_plugin` 未从 CommandRouter 取消注册**：已禁用的插件的 `@command` 指令不再可被路由触发

### 插件加载时序
- **SPA 兜底路由拦截插件 UI 请求（404）**：`_insert_plugin_routes` 方法确保插件路由优先于 `/{full_path:path}` 匹配
- **`set_app` 在插件就绪前被调用**：`set_app` 现在在 `load_all()` 之后、`resume_all()` 之前执行
- **composite/form 类型无限加载**：无 `api` 字段的类型现在初始化时直接设置 `loading=false`
- **Hooks 顺序违规**：`formInited` 状态提升至顶层，所有 hooks 在所有渲染中保持一致顺序

### 路由注册
- **插件路由使用原始插入绕过 FastAPI APIRoute 初始化导致 422**：改为 `app.include_router` 并临时移除兜底路由确保正确放置
- **`_app` 未设置时 `_ensure_plugin_loaded` 输出 WARNING**：服务器通过 `set_app` 提前注入 app 引用

### 其他
- **插件 `_server` 引用从未注入**：`PluginManager` 现在将 `MissevanServer` 注入插件实例，使 `/rooms` 等端点可访问直播间列表
- **`retry_failed_plugin` 未移除旧条目**：重试前先清除 `_plugins` 中的旧元数据
- **JSON 嵌套模板字面量导致 Babel 解析崩溃**：所有 JSX `className` 模板字面量替换为字符串拼接 + 预计算变量

## 🔧 改进优化

- **插件 `register_routes` 签名**：`router: object` → `router: Any`，移除导致 PyCharm 类型检查告警的 `TYPE_CHECKING fastapi` 导入
- **`example_plugin` 升级为类型演示套件**：复合页面展示 `stats` + `table`（8 种列类型）+ `form`（3 种控件）
- **示例 schema 文件**：`_ui_schema.stats.json`、`_ui_schema.form.json` 供快速切换测试
- **"主页"按钮行为**：从 `target="_blank"` 改为当前标签页内导航
- **插件 UI 刷新**：`handleToggle` 失败后仍刷新列表，确保失败插件立即显示
- **`test/` 目录从 Git 追踪中移除**
