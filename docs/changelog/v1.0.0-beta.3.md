## ⚡ 破坏性变更

- **插件启停语义重构**：插件开关（`enabled` 标记）仅控制持久化状态，实际加载由 Bot 启停状态联动决定——Bot 停用时插件全部暂停，Bot 启用时自动恢复
- **默认端口变更**：API 端口 `8080` → `18080`，Web 端口 `5173` → `15173`（可通过 `config.yml` 或环境变量覆盖）
- **插件详情交互重构**：移除卡片"详情"入口，抽屉改为**居中弹窗**，各功能以图标实体按键直达

## ✨ 新增功能

### 登录认证系统

- 默认账号 `MisMiss / MisMiss`，SHA-256 哈希存储于 `data/auth.json`（文件缺失/损坏自动重建默认值）
- 首次登录强制修改密码（无需旧密码验证 + 确认密码一致性校验）
- 修改密码/用户名入口内置于设置页"账户安全"板块，非首次修改需输入当前密码
- Token 有效期 30 天；修改密码后清空全部会话，强制重新登录
- 全局 API 鉴权中间件——`/api/auth/*`、`/api/health`、`/api/ws`、`/api/proxy/*`、插件 UI 路由豁免

### 插件启停状态机

| 操作 | 行为 |
|------|------|
| 插件开关 | 仅更新 `enabled` 标记 + 持久化到状态文件 |
| Bot 启用 | `resume_all()` 恢复所有标记为启用的插件 |
| Bot 停用 | `suspend_all()` 暂停全部插件（不改持久化标记） |
| 插件重载 | 保留启停标记，重载后按标记恢复 |
| Cookie 更新 | 停用插件 → 切换新 Bot → 刷新直播间引用 → 恢复插件 |
| 配置保存 | 运行中的插件自动热重载（`reload_plugin` + `enable_plugin`） |

### 实时日志系统

- 后端 `RingBuffer`（10000 条环形缓冲 + 全局递增 seq_id）
- WebSocket 实时推送 + 断线重连补发（`last_seq` 机制）
- HTTP 历史查询接口 + 滚动分页 + **闲时自动加载**（`requestIdleCallback` 逐批拉取全部历史）
- 前端 `react-virtuoso` 虚拟滚动，万条日志不卡顿
- 多选日志级别筛选 + 关键词搜索 + ANSI 颜色解析
- DEBUG 输出开关持久化到 `config.yml`，重启生效
- 日志页内置 pip 包安装按钮

### 插件安装/更新流程

- zip 上传安装：解压 → 读 metadata → 重名检测 → 版本比对 → 安装依赖 → 默认启用
- 同名高版本弹窗确认更新（版本对比展示），更新后小窗展示 CHANGELOG
- 失败插件显示完整 Traceback（小窗查看 + 主题适配）

### 移动端全面适配

- 底部导航栏 → **左侧抽屉式菜单**（监控/管理/系统三组 + 退出登录）
- 插件详情改为居中弹窗（`85vh` 圆角，桌面/移动统一形态）
- 直播间卡片视图、发送弹幕输入优化（数字键盘唤起、按钮不溢出、自定义下拉选择器）
- 长文本 **MarqueeText 跑马灯**（恒定速度 + 固定两端停留 + 精确距离无空白）
- 插件卡片图标按钮 + 自定义主题 tooltip（悬浮即时显示）
- 配置表单保存/重置按钮常驻底部（内部滚动区，不遮挡）

### 端口与部署

- WebUI 可修改 API 端口（保存后自动重启后端，Web 端口仅启动脚本可改）
- `start.bat` 支持 dev / prod / build 三种模式 + 端口占用检测防重复启动
- `BUILDING.md` 完整构建部署指南
- PyInstaller spec 重构（`collect_submodules` 自动收集依赖，pip 内嵌支持插件依赖安装）
- Docker 多阶段构建 + docker-compose 一键部署

## 🐛 Bug 修复

### P0 级别

- **`_plugins` 属性未初始化导致启动崩溃**：`load_all()` 前访问 `get_plugin()` 触发 AttributeError
- **插件初始化失败后 `plugin_instance` 被清空导致 UI 路由 404**：失败时保留实例引用，仅标记 `enabled=False`
- **UI 路由 422（Field required）**：动态通配路由与 `include_router` 注册路由冲突，移除通配分发器

### 插件系统

- **`set_app` 时序错误**：`start()` 内部创建新 PluginManager 后 app 引用丢失，调整为先 `start()` 后 `set_app()` 再补注册路由
- **插件加载失败后持久化丢失**：失败插件保留在 `_plugins`（`enabled=False`），状态文件不再丢条目
- **配置保存后不生效**：保存配置端点现在自动热重载运行中的插件
- **`enable_plugin` 静默吞错**：同步加载失败输出完整错误日志

### 直播间

- **移除已停用直播间 500**：`remove_livestream` 捕获 `CoreDisabledException`
- **新添加直播间默认启用但未连接**：`add_livestream` 显式设置 `enabled=False`
- **`disable_livestream` 异步任务未处理异常**：`_safe_quit` 包装静默吞掉已停用异常
- **未开播直播间报错刷屏**：`500030011`（主播休息）降级为 debug 静默忽略（普通消息与定时消息双路径）

### 日志系统

- **多实例 MarqueeText 动画互相覆盖**：keyframes 注入 `textContent =` → `+=` 追加模式
- **日志加载跳转与阻塞**：PAGE_SIZE 优化 + 闲时加载 + `firstItemIndex` 滚动锚定 + 批间让出主线程
- **WebSocket 混合内容警告**：HTTPS 页面自动使用 WSS 同源连接

### 前端交互

- **插件开关反复横跳**：乐观更新 + 加载中滑块保持原位 + 背景保持原状态色
- **Bot 状态徽章移动端折行**：`shrink-0 whitespace-nowrap` 保持单行
- **CORS 预检 401**：OPTIONS 请求跳过鉴权中间件
- **FormData 上传缺 Authorization 头**：插件安装/更新请求补全认证头
