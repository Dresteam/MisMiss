## ⚡ 破坏性变更

- **插件启停语义重构**：插件开关（`enabled` 标记）仅控制持久化状态，实际加载由 Bot 启停状态联动决定

## ✨ 新增功能

### 登录认证系统

- 默认账号 `MisMiss / MisMiss`，SHA-256 哈希存储于 `data/auth.json`
- 首次登录强制修改密码（无需旧密码 + 确认密码校验）
- Token 有效期 30 天，修改密码后全部会话失效强制重登
- 全 API 鉴权中间件（`/api/auth/*`、`/api/health`、`/api/ws`、插件 UI 路由豁免）
- 修改密码入口内置于设置页"账户安全"板块

### 插件启停状态机重构

| 操作 | 行为 |
|------|------|
| 插件开关 | 仅更新持久化标记 + 状态文件 |
| Bot 启用 | 自动恢复所有标记为启用的插件 |
| Bot 停用 | 暂停全部插件（`suspend_all`，不改变持久化） |
| 插件重载 | 保留启停标记，重载后自动恢复 |
| Cookie 更新 | 停用插件 → 切换新 Bot → 更新直播间引用 → 恢复插件 |

### 实时日志系统

- 后端 RingBuffer（10000 条环形缓冲 + 全局 seq_id）
- WebSocket 实时推送 + 断线补发（`last_seq` 机制）
- HTTP 历史接口 + 滚动分页加载
- 前端 react-virtuoso 虚拟滚动，万条日志不卡顿
- **闲时自动加载**：浏览器空闲时逐批加载全部历史（requestIdleCallback）
- 多选日志级别筛选 + 关键词搜索 + ANSI 颜色解析
- 日志页内置 pip 包安装按钮
- DEBUG 输出开关持久化到 `config.yml`，重启生效

### 插件安装/更新流程

- zip 上传安装：解压 → 读 metadata → 检测重名 → 安装依赖 → 默认启用
- 同名高版本弹窗确认更新（UpdateDialog 展示版本对比）
- 更新后小窗展示 CHANGELOG 更新公告
- 失败插件显示完整错误 Traceback（小窗查看）

### 移动端全面适配

- 底部导航栏 → **左侧抽屉式菜单**（监控/管理/系统分组 + 退出登录）
- 插件详情改为**居中弹窗**（桌面/移动统一形态）
- 直播间卡片视图、发送弹幕布局优化（数字键盘、按钮不溢出）
- Bot 名字等长文本 **MarqueeText 跑马灯**（恒定速度 + 固定停留 + 精确距离无空白）
- 插件卡片图标按钮 + 自定义主题 tooltip（悬浮即时显示）
- 配置表单保存/重置按钮常驻底部（独立滚动区，不遮挡）

### 端口与部署

- WebUI 可修改 API 端口（保存后自动重启后端）
- `start.bat` 支持 dev/prod/build 三种模式 + 端口检测防重复启动
- `BUILDING.md` 完整构建部署指南
- PyInstaller spec 重构（collect_submodules 自动收集依赖）
- Docker 多阶段构建 + docker-compose 一键部署

## 🐛 Bug 修复

### 插件系统
- **`_plugins` 属性未初始化**导致启动崩溃（`load_all` 前访问）
- **插件初始化失败后 `plugin_instance` 被清空**导致 UI 路由 404：失败时保留实例
- **`set_app` 时序错误**：`start()` 内创建新 PluginManager 后 app 引用丢失，调整为先 `start()` 后 `set_app()`
- **UI 路由 422**：动态分发路由与注册路由冲突，移除通配分发器统一走 `include_router`
- **插件配置保存后不生效**：运行中的插件配置保存后自动热重载
- **`enable_plugin` 静默吞错**：同步加载失败现在有完整错误日志

### 直播间
- **移除已停用直播间 500 错误**：`CoreDisabledException` 容错处理
- **新添加直播间默认启用但未连接**：显式设置 `enabled=False` 消除状态不一致
- **`disable_livestream` 异步任务异常**：`_safe_quit` 包装吞掉已停用异常
- **未开播直播间报错刷屏**：`500030011`（主播休息）降级为 debug 静默忽略

### 日志系统
- **多实例 MarqueeText 动画互相覆盖**：keyframes 注入改为追加模式
- **日志加载跳转/阻塞**：PAGE_SIZE 优化 + 闲时加载 + firstItemIndex 锚定
- **WebSocket 混合内容警告**：HTTPS 页面自动使用 WSS 同源连接

### 前端交互
- **插件开关反复横跳**：乐观更新 + 加载中滑块保持原位 + 背景保持原状态色
- **状态徽章移动端折行**：`shrink-0 whitespace-nowrap` 保持单行
- **CORS 预检 401**：OPTIONS 请求跳过鉴权中间件
- **FormData 上传缺 Authorization**：插件安装/更新请求补全认证头

## 🔧 改进优化

- 未开播直播间消息静默忽略（不刷警告日志）
- 插件失败后保留 `_plugins` 条目防止持久化丢失
- 启动时 Bot 停用则跳过插件恢复（保留标记）
- 启动完成后立即 `_save_state()` 确保状态落盘
- `_save_state` 原子写入（tmp + replace 防崩溃损坏）
- MarqueeText 跑马灯组件（`w-max` + `getBoundingClientRect` 精确测量 + ResizeObserver）
- Button 组件新增 `tooltip` 自定义悬浮提示（主题自适应）
