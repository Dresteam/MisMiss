## ✨ 新增功能

### 定时消息队列管理

新增 `TimerPage`（Web 控制台「定时消息」页），完整管理 Bot 定时播报队列：

| 能力 | 说明 |
|------|------|
| 全局队列 | `live_id=0` 的全局消息，所有直播间轮播 |
| 直播间队列 | 每个直播间独立的定时消息列表 |
| 合并轮转 | 每个直播间按「全局消息在前、独立消息在后」组成合并轮转，**每个间隔只发送一条**，确保消息不会同时发送 |
| 倒计时 | 每条消息按轮转位置显示距执行的真实秒数，取模滚动持续同步 |
| 添加 | 指定直播间（0=全局）+ 消息内容，**暂无直播间时也可添加** |
| 编辑 | 修改消息文本，无需删除重建 |
| 删除 | 移除指定消息 |
| 排序 | 在所属队列内上移/下移 |
| 跳过一次 | 仅对当前指针处的待执行消息可用：**指针直接后移一位，计时器保持** |
| 立即发送 | 发送待执行消息并推进指针（全局消息需指定目标直播间） |
| 间隔实时修改 | 修改后立即生效且**持久化到 `config.yml`**，重启不丢失 |
| 静默刷新 | 操作后仅刷新列表数据，不闪整页（含 30 秒自动校准） |

新增 API：`GET /api/timer/list`、`PUT /api/timer/interval`、`POST /api/timer/add`、`PUT /api/timer/{id}`、`DELETE /api/timer/{id}`、`POST /api/timer/{id}/move`、`POST /api/timer/{id}/skip`、`POST /api/timer/{id}/send`。

### 程序更新系统

新增 `UpdatePage`（Web 控制台「程序更新」页），以 GitHub Releases 为更新源，界面仿照 AstrBot 更新页：

| 能力 | 说明 |
|------|------|
| 最新版本卡片 | 显示最新版本号、发布日期与更新日志（可折叠预览 / 展开完整 Markdown） |
| 版本列表 | 标签 / 发布时间 / 操作三列表格，每页 6 条分页，支持「切换」到任意版本 |
| 查看日志弹框 | 任意历史版本的完整更新日志以弹框展示 |
| 预发布过滤 | 「显示预发布版本」开关 + 版本标签旁「预发布」徽章 |
| 语义版本比较 | 按版本号（非发布时间）判断新旧，补发旧版本不会误判为「新版本」 |
| 执行更新 | 备份当前版本 → 下载资源 → 解压覆盖 → 重启 |
| 回滚 | 一键恢复备份的上一版本 |
| 镜像站下拉 | 内置 gh-proxy.com / ghproxy.net / mirror.ghproxy.com / ghfast.top / hub.gitmirror.com 常用镜像 + 自定义地址；镜像同时加速 **API 与下载**（兼容旧格式完整地址） |
| 代理 | HTTP 代理配置 |

新增 API：`GET /api/update/info`、`GET /api/update/check`、`GET /api/update/changelog/{version}`、`POST /api/update/settings`、`POST /api/update/apply`、`POST /api/update/rollback`。

配置项（`config.yml`）：

```yaml
update:
  repo: Dresteam/MisMiss     # GitHub 仓库
  mirror: ""                  # 镜像站前缀（可选），如 https://gh-proxy.com/
  proxy: ""                   # HTTP 代理（可选）
```

## 🐛 Bug 修复

### 定时消息
- **全局与独立消息同时发送**：改为合并轮转，每个间隔只发一条
- **跳过一次按钮无反应**：旧版前端读不到新接口指针字段导致按钮全部禁用；跳过一次改为「指针后移 + 计时器保持」的即时语义
- **间隔修改丢失**：修改发送间隔后立即持久化到 `config.yml`（原子写入），异常关闭 / 重启不丢失
- **无直播间无法添加消息**：空状态提供添加入口，纯全局消息也能正常展示

### 程序更新
- **旧版本被误判为新版本**：GitHub Releases 按发布时间倒序，补发的 beta.2 排在 beta.3 前导致误判；改为语义版本比较 + 按版本号排序
- **镜像自定义地址无法选择**：镜像下拉框与值解耦，增加独立的自定义模式状态
- **镜像仅加速 API**：下载更新包现在同样走镜像前缀

### Docker 部署修复
- **多 worker 状态不一致**：`_ensure_state_fresh()` + `get_server()` 自动同步；`WORKERS=1` 彻底消除
- **Token 存储**：内存字典 → `data/tokens/` 文件（跨 worker 共享）
- **WebSocket Cookie 为空**：`DefaultCookieAPI` 添加浏览器请求头（412 修复）
- **pip 安装后包不可见**：`--user` 安装 + `pip show` 定位 + `sys.path` 自动注入
- **CRLF 换行符**：`.gitattributes` 强制 shell 脚本 LF

### 登录认证
- **首次登录会话过期**：`/api/auth/check` 验证 token；新增跳过引导端点；AccountSetup 不再无限循环
- **`/api/health` 404**：端点移至 SPA fallback 之前

### 插件系统
- **流式安装日志**：`POST /api/plugin/install/stream`（SSE）+ `InstallModal` 实时显示
- **安装互斥锁**：`asyncio.Lock` 确保同一时间只有一个安装操作
- **依赖检测**：`importlib.util.find_spec()` 替代不可靠的双重检测

### 日志系统
- **第三方库 DEBUG 噪音**：`httpcore` / `httpx` / `websockets` / `urllib3` / `asyncio` 的 DEBUG 日志（连接层 open/close 等）统一抑制为 WARNING，Web 日志页不再刷屏

- **深色模式重构**：暗蓝色 slate 色系全面替换为中性灰 zinc 色系，对比更柔和、更护眼；蓝色仅保留为交互点缀色
- **移动端适配**：跑马灯组件（长标题滚动）、抽屉式导航、响应式布局
- **插件启停重构**：API 端点统一委托 server 方法，移除状态不一致路径
- **日志闲时加载**：虚拟滚动 + 按需加载
- **设置页精简**：「定时消息」板块移除（发送间隔统一在定时消息页管理）
- **版本拉取量**：更新检测从默认 30 条提升至 100 条（`per_page=100`）
