自 v1.0.0-beta.1 以来，历经三个 beta 版本迭代，MisMiss 正式发布 **v1.0.0**。

## ⚡ 破坏性变更

- **插件 `_ui_schema.json` 格式升级**：新增 `composite`、`form`、`playlist` 页面类型；`columns[].type` 扩展为 `badge | link | switch | text | number | date | image`
- **`Plugin.data` 属性强制注入**：插件必须通过 `self.data.read_json / write_json` 进行数据文件读写，路径沙箱禁止逃逸与绝对路径

## ✨ 新增功能

### 定时消息队列

- **合并轮转**：全局消息（`live_id=0`）+ 直播间独立消息按「全局在前、独立在后」组成合并轮转，每个间隔只发送一条，确保消息不会同时发送
- **实时管理**：添加/编辑/删除/排序；倒计时按轮转位置精确显示并取模滚动同步
- **跳过一次**：指针直接后移一位、计时器保持；「立即发送」推进指针
- **间隔持久化**：修改发送间隔实时生效并原子写入 `config.yml`，重启不丢失
- **界面细节**：无直播间也可添加消息；直播间选择框显示房间名（超长自动滚动）；消息内容跑马灯；操作后静默局部刷新

### 程序更新系统

- **AstrBot 风格界面**：最新版本卡片（日志预览/展开）、版本列表表格（标签/发布时间/操作）、每页 6 条分页、预发布过滤与徽章、任意版本查看日志弹框
- **语义版本比较**：按版本号（非发布时间）排序与判定，补发旧版本不会误判为「新版本」
- **镜像站下拉**：内置 gh-proxy.com / ghproxy.net / mirror.ghproxy.com / ghfast.top / hub.gitmirror.com + 自定义地址；镜像同时加速 API 与下载
- **完整更新流程**：备份当前版本 → 下载 → 解压覆盖 → 自动重启；一键回滚

### 实时日志系统

- **批量推送**：WebSocket 每 200ms 合并广播，帧数大幅下降
- **源头级别过滤**：级别筛选下推到后端，DEBUG 刷屏时前端几乎零流量
- **增量筛选**：切换筛选先本地过滤已加载日志，再向后端补拉，数量精确一致
- **按需加载**：单次 100 条，滚动到顶时加载更早历史；加载期间冻结渲染，无列表抖动
- **固定行高**：日志行单行截断、点击展开全文；第三方库 DEBUG 噪音统一抑制

### 事件系统扩展

- **提问事件**：`LiveQuestionEvent`（`question:ask`），含问题文本、价格、状态、点赞等完整字段
- **实时统计事件**：`LiveStatisticsEvent`（`room:statistics`），携带热度 / 在线人数 / VIP 人数
- **直播间在线人数接口**：`Livestream.online_count`，通过统计事件实时更新；热度同步自动更新，前端 8 秒轮询即时可见

### 插件系统

- **声明式 Web UI**：7 种页面类型（stats / table / list / cards / playlist / form / composite）、8 种列渲染类型、表单构造器（7 种控件）
- **PluginDataManager 数据沙箱**：`read_json / write_json / read_text / write_text / delete / exists`
- **多直播间点播单**：`room_id` 隔离、房间选择器、批量状态操作、清空二次确认
- **权限系统**：`BotPermission` 双层权限 + 插件级实时拦截（`contextvars`）；插件权限逐项可改并持久化
- **全生命周期**：安装（URL/本地/流式 SSE 日志）、启停、重载、卸载；失败插件追踪与重试
- **指令注解**：`@command` 弹幕文本自动解析为结构化指令调用

### 登录认证

- 默认 MisMiss / MisMiss，SHA-256 哈希存储，首次登录强制改密；Bearer token 保护全部 API

### 界面与体验

- **导航重构**：监控 / 管理 / 系统分组菜单（桌面与移动端一致），左上角显示当前版本号
- **统一悬浮提示**：`HoverTip` 组件替代原生 title，深色圆角气泡、主题自适应
- **深色模式**：zinc 中性灰配色，去除暗蓝色调，更护眼更现代
- **Markdown 渲染增强**：GFM / 数学公式 / 内联 HTML；未指名语言代码块按纯文本解析
- **移动端适配**：抽屉导航、跑马灯标题、响应式卡片布局

## 🐛 Bug 修复

- 定时消息全局与独立消息同时发送 → 合并轮转每间隔一条
- 定时消息跳过一次按钮无反应 / 延迟生效 → 指针后移即时语义
- 程序更新旧版本被误判为新版本（GitHub Releases 按发布时间倒序）→ 语义版本排序
- 日志页整页闪烁、向上加载跳动、筛选数量不一致 → 静默刷新 + useLayoutEffect 锚定 + 连续翻页补拉
- Docker 多 worker 状态不一致 → state 文件 mtime 同步 + token 文件共享
- 插件启用初始化失败后状态错误、禁用后指令仍可路由、SPA 兜底路由拦截插件 UI → 逐一修复
- `httpcore` 等第三方库 DEBUG 噪音刷屏 → 统一抑制为 WARNING
- WebSocket Cookie 为空（412）、pip 安装后包不可见、CRLF 换行符等部署问题

- 测试工具 `scripts/ws_watch.py`：直播间 WebSocket 检测（心跳/重连/原始消息输出）
