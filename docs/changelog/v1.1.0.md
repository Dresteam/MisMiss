v1.1.0 是一次整体架构升级:
主面板从「单服务器仪表盘」重构为 **Server(账户) 管理后台**（面板 + 账户独立门户）,
重构插件运行模型（副本隔离）,并新增 **Docker 部署包流程与 Web 在线更新**能力。

## ⚡ 破坏性变更

- **数据模型重构(全新开始)**:升级时旧单服务器数据自动备份到
  `data/backup/pre-multiaccount-<时间戳>/`,`auth.json` 面板管理员登录保留,其余全新配置
- **API 全面账户化**:`/api/bot`、`/api/live`、`/api/timer` 移除,迁移至
  `/api/accounts/{id}/...`;`/api/dashboard` 移除,由 `/api/panel/overview` 取代;
  插件启用/配置迁移至账户级,`/api/plugin` 变为插件库(面板级)
- **插件运行模型变更**:账户从插件库「安装」插件 = 拷贝源码副本到
  `data/accounts/{id}/installed_plugins/` 独立运行;「卸载」删除副本
  (可选删除配置/持久化数据);「启用/禁用」为启动/停止实例
- **插件全面去除直播间维度**(12 个插件):移除 `enabled_rooms`/`allowed_rooms`
  配置与房间过滤,数据按房间分区改为账户级单份(旧数据全新开始不迁移);
  `timer_messages` 配置改为每行一条消息(不再需要「直播间ID:」前缀);
  `song_request` 移除 standalone 独立前端
- **创建账户用户名必填且全局唯一**(用于账户分辨),旧账户自动补录
  `account{id}` 用户名
- **一个账户仅一个直播间**:定时消息简化为账户单队列(live_id 固定为 global 队列)
- 插件 UI 路由账户化(`/api/accounts/{id}/plugin/{name}/ui`),插件 schema
  内硬编码路径由前端自动重写
- **Docker 部署方式变更**:废弃 ghcr.io 镜像仓库与 CI/CD 推送,改为本地构建
  **部署包**(镜像 + compose + 一键部署脚本)分发,服务器 `bash deploy.sh`
  一条命令完成部署/更新

## ✨ 新增功能

### Server(账户) 管理后台与账户独立门户

- 每个账户 = 1 个直播间 + 1 个 Bot,面板支持创建/删除/管理
- 账户总览卡片:房间、Bot 状态、插件启用数、定时消息数、订阅状态,10s 自动刷新;
  账户详情页(5 个标签页):概览 / 直播间 / Bot / 定时消息 / 插件
- 到期前 7 天琥珀色提醒、已过期红色徽标;续期/兑换弹框
- **账户子域名入口**(如 `user.localhost:15173`):账户凭据登录,
  身份由用户名/密码决定,管理员凭据拒绝进入;无任何面板功能;
  账户可**自助兑换授权码**(过期账户亦可兑换,自动恢复运行)

### Bot 双模式

- **私有 Cookie**:账户独立配置,可查看/更新
- **公共 Cookie**:面板统一配置,多账户并发共享(每账户独立会话);
  账户上下文不可查看 Cookie(403 守卫);一键下发到全部公共账户
- 账户可**自行切换公共/自定义 Cookie**;切换后 Bot 卡片即时更新
- **公共 Cookie 权限强制「仅发送直播间消息」**(后端强制,设置页不再可选);
  自定义 Cookie 支持完整权限勾选设置
- 公共 Bot 卡片:头像(图片代理)/名称/ID/简介/权限徽章,查看/刷新/验证/删除 Cookie

### 直播间富信息

- 卡片展示:封面图、开播状态(开播中/未开播)、主播头像/名称/在线状态/简介、
  房间名/简介、热度、在线人数、粉丝勋章
- **启用即自动进入**(移除单独「进入」按钮);支持**更换绑定直播间**
  (安全顺序:新房间添加成功后才移除旧房间)

### 插件体系(副本隔离)

- 插件实例、配置、权限、数据**按账户完全隔离**(`data/accounts/{id}/`)
- per-account 事件总线与命令路由:各账户房间的弹幕只触达自己的插件实例,
  同名插件多账户启用互不冲突;插件更新后各账户已启用实例自动重载
- 插件库详情抽屉:文档 / 更新日志 / 使用账户(账户名 + ID);卡片按钮图标 + 悬浮提示
- 已安装插件与库版本对比,**显示「可更新」徽标**(悬浮显示最新版本)
- 卸载对话框:可选删除配置文件/持久化数据 + 不可撤销警告

### 商业授权 / 订阅系统

- 账户 `expires_at` 到期时间(永久可选)
- **到期硬停用**:自动停用 Bot、断开房间、暂停插件(保留启用标记);
  过期账户全部写操作 403;60s 调度器兜底 + 端点守卫
- **续期自动恢复**:到期原因暂停的账户,续期后自动恢复 Bot/房间/插件,
  失败原因展示在 `resume_error`
- **授权码系统**:`MM-XXXX-XXXX-XXXX` 批量生成(数量/天数/备注)、
  兑换叠加天数(`max(now, expires_at)` 起算)、已用标记与撤销;
  面板支持手动改期与授权码两种续期方式

### 定时消息

- 间隔卡/直播间行/消息卡布局;倒计时胶囊(X分Y秒)
- **倒计时实时更新**(本地 1s 递减 + 30s 重同步)
- 仅指针处(▶ 即将执行)消息可跳过/立即发送;删除二次确认弹窗

### Docker 部署包与 Web 在线更新

- **部署包流程(不推镜像仓库)**:本地一条命令构建镜像并打包
  (`mismiss-<版本>-docker.zip / .tar.gz`,扁平结构),服务器解压后
  `bash deploy.sh` 一键导入镜像、引导配置、启动;更新覆盖部署目录后重复执行即可
- **Web 控制台在线更新**:「更新 MisMiss」页手动点击,自动完成
  下载部署包(复用镜像站/代理)→ 校验 → 备份 → 解压 → 导入镜像 → 重建容器
  (约 10~30 秒),更新前整包备份,**支持一键回滚**
- 统一 compose 部署栈(应用 + Nginx),默认单 worker(`MISMISS_WORKERS=1`),
  固定容器 uid=1000 兼容绑定挂载;未挂载 docker.sock 时更新页自动提示并回落手动流程

## 🐛 Bug 修复

- **定时消息倒计时恒为 0s 且消息从未发送**:计时引擎只检查房间队列,
  账户消息注册在 global 队列导致循环未启动 → 引擎同时检查两类队列,
  账户消息注册到账户直播间队列
- 插件卸载后仍显示在已安装列表(load_all 增量合并不清理消失目录)
- 面板插件库详情 404(详情端点已账户化)→ 改用库列表元信息
- 公共 Bot 卡片 `updated_at` 类型不一致导致 500
- 点击抽屉图标按钮跳转错误标签(事件先于组件挂载丢失)→ `initialTab` prop
- 折叠侧边栏悬浮提示被 Logo 遮挡/裁切 → 右侧气泡 + overflow-visible
- 账户总览头部与账户详情标签栏移动端适配(按钮换行、均分无滚动条)
- 更换直播间失败时旧房间(记录 + 运行时连接)完整保留
- 插件 UI 路由前缀硬编码导致多账户路由冲突 → 参数化
- 账户级定时消息间隔写入全局 config.yml 互相覆盖 → per-account 持久化
- 空 tokens 目录被迁移误判为旧数据 → 迁移跳过空目录
- 面板启动时 tokens 目录可能尚未创建 → 写入前自动创建
- **内置更新器在 Docker 下误用/失效**:容器重建后更新丢失、config.yml 只读挂载
  导致解压失败、资产误选 docker 部署包、归档顶层目录未剥离导致程序文件
  从未被覆盖 → Docker 下改为在线更新路径,原生路径修复资产选择与解压层级
- Docker 部署包嵌套 tar 导致服务器 `docker load` 报
  `unrecognized image format` → 打包改为 buildx 导出经典格式 + gzip 直接压缩
- Docker 构建若干问题:ARG 跨阶段作用域失效、BuildKit apt 缓存挂载损坏、
  GitHub 下载 302 重定向未跟随导致 compose 插件 0 字节

## 🔧 改进优化

- `MissevanServer` 参数化:data_dir / 插件库目录 / 定时间隔持久化位置 /
  `auto_resume` 冷启动,每账户独立实例复用现有状态持久化机制
- `MISMISS_DATA_DIR` 环境变量支持(数据卷分离 / 测试隔离)
- 插件 UI 路由前缀参数化(`PluginManager.ui_route_prefix`),前端 `PluginUI`
  新增 `apiBase` prop
- 旧页面(Dashboard/Bot/Live/Timer/Plugin)删除,导航重构为
  监控(账户总览/日志)/ 管理(插件库)/ 系统
- 12 个插件版本 +0.0.1 标记多账户适配
- 回归测试:账户管理 / API 集成 / 授权码 / 插件副本安装卸载 / 定时持久化
- 镜像内置 docker CLI + compose 插件 + gosu(入口脚本匹配 socket 属组后降权),
  构建时注入 `MISMISS_VERSION` 供更新页展示;gunicorn `--timeout 1800`
  避免在线更新的大包下载误杀请求
- 版本号运行时解析(环境变量 → `pyproject.toml` → 兜底),更新页版本展示
  与发布版本保持一致

## ⚠️ 已知限制

- 插件模块级全局变量跨账户共享(`sys.modules` 缓存)——插件需只使用实例级状态
- 必须单 worker 部署(`MISMISS_WORKERS=1`)
- 建议账户规模 ≤ 30~50;公共 Cookie 并发受平台限流约束
- 在线更新依赖容器挂载 `/var/run/docker.sock`(等效宿主 root 权限,
  Portainer / Watchtower 同款模式);删除 compose 中对应挂载即可禁用,
  更新回落部署包流程
