<div align="center">

**账户凭据自助管理 · 管理端一键装插件 · 插件主页修复 · 移动端适配**

v1.1.1 是一次体验与稳定性更新:补齐账户用户自助修改密码能力,
管理端账户详情可直接从插件库安装插件,并修复插件主页 404 与
悬浮提示遮挡等一系列多账户架构迁移遗留问题。

## ✨ 新增功能

### 账户自助修改密码

- **需输入原密码 + 新密码 + 确认密码**:原密码错误 403、两次输入不一致 400、
  新密码至少 4 位;修改成功后该账户全部登录 token 立即失效,强制重新登录
- 用户端新增「系统 → 修改密码」页面(桌面侧边栏与移动端菜单双入口),
  成功后提示并自动登出;后端新增 `POST /api/accounts/{id}/change-password`
  与账户级 token 清理能力(多 worker 下通过 token 文件共享生效)

### 管理端账户详情「插件库」Tab

- 账户详情页由 5 个标签扩展为 6 个:**概览 / 直播间 / Bot / 定时消息 / 插件 / 插件库**
- 管理员可在插件库 Tab 直接为当前账户安装插件(安装后默认停用,
  到「插件」Tab 启用与配置),已安装的显示「已安装」标识
- 「插件」Tab 的插件库按钮改为**切换 Tab**(管理端),账户门户保持路由跳转

### 插件 UI 能力增强

- **多字段输入弹窗**(`prompt_fields`):一次弹窗收集多个字段
  (文本 / 数字 / 下拉选择),替代单输入框限制
- **按钮显示控制**(`row_only` / `toolbar_only`):新增类按钮仅工具栏显示,
  删除类按钮仅行内显示

## 🐛 Bug 修复

- **插件主页操作 404**:PluginUI 仅重写数据接口路径,动作 URL
  (添加/提交/开关/批量)仍用旧版 `/api/plugin/...` 硬编码路径 →
  统一 `rewriteUrl` 覆盖全部动作与 composite 子页面
- **安装插件后插件主页 404**:新安装插件处于禁用状态仅加载元数据,
  UI 路由须等到启用或重启才注册 → 安装后立即创建轻量实例注册路由
- **插件页插件库按钮跳转错误**:管理端点击被重定向到账户总览 → 改为切换 Tab
- **点播单操作按钮悬浮提示被遮挡**:气泡位于滚动容器内,
  受 overflow 裁剪与「已完成」行 `opacity` 层叠上下文遮挡 →
  改为 portal 渲染到 `document.body`(fixed 定位 + 最高层级),
  并随滚动自动隐藏
- **到期徽标「剩余 X 天」不更新**:徽标按渲染时时间计算,页面停留期间
  不再重算 → 内置每分钟定时器自动刷新(剩余天数递减、≤7 天变色、
  到期变红均实时生效)
- 禁用 `message:cross_new` 事件映射,避免跨房间消息重复触发消息处理器

## 🔧 改进优化

- 用户端插件库刷新按钮移动端适配(头部换行 + 按钮防收缩),
  插件 Tab 头部同步适配
- 用户端移动端菜单补齐「修改密码」入口,与桌面侧边栏导航一致
- 插件库页与账户详情插件库 Tab 复用同一 `LibraryTab` 组件,消除重复实现
