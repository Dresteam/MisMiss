# 🚀 MisMiss v1.1.2 — 设置剩余天数 · 插件页返回修正 · 插件路由清理

<div align="center">

**到期时间直接可设 · 插件主页返回插件界面 · 服务器状态精确展示 · 插件路由生命周期治理**

</div>

---

v1.1.2 是一次小版本体验修正:管理端可把到期时间直接设置为「剩余 N 天」
(永久账户可改为限时),插件主页返回直达插件界面,并修复插件重载/卸载后
旧实例路由抢占导致的 Web UI 与数据不同步。

## ✨ 新增功能

### 管理端「设置剩余天数」

- 续期之外新增**直接设置到期时间**能力:输入 N 天即把到期时间覆盖为
  「当前时间 + N 天」(忽略原到期时间),用于**将永不过期账户改为限时**、
  或把剩余天数直接调整为指定值;续期(N 天叠加)语义保持不变
- 入口:账户总览卡片操作区新增 ⏳「设置剩余天数」图标按钮;
  账户详情页头部新增「设置剩余」按钮(兑换 / 设置剩余 / 续期)

## 🐛 Bug 修复

- **插件主页返回按钮指向错误**:此前返回账户总览/主页 →
  改为返回插件界面(用户端 `/account/plugins`,管理端直达账户详情插件 Tab);
  账户详情页 Tab 与 URL(`?tab=`)双向同步,浏览器前进/后退同样正确还原
- **插件重载/重新激活后旧实例路由抢占**:旧实例的过期 UI 路由仍留在
  FastAPI 路由表中抢先匹配,导致插件主页展示与直播间实际数据不同步 →
  注册新路由前自动移除同前缀旧路由
- **卸载插件后 UI 路由残留**:实例卸载后旧路由仍可响应请求 →
  卸载时同步移除该插件的全部 UI 路由(兼容新版 Starlette
  `_IncludedRouter` 包装的前缀提取)
- **服务器运行状态插件数显示混乱**:「插件」卡片原显示
  `已启用/库总数`(如 12/44),现仅显示**已启用数**,避免与库插件总数混淆

## 🔧 改进优化

- 账户详情页头部按钮区移动端适配(可换行防挤压)
- 续期弹窗模式化重构:标题 / 输入标签 / 说明文案按模式(续期 / 设置剩余 /
  兑换)区分,「设置剩余天数」模式附带语义说明
