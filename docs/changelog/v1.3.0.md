# 🚀 MisMiss v1.3.0 — 统一登录 · 事件编排 · 专属昵称

<div align="center">

**一个域名登录 · 插件事件可编排 · 观众可设专属昵称 · 更新后自动告知**

</div>

---

v1.3.0 是一次以**体验与可扩展性**为主的版本:

- **登录入口统一**——不再区分 `user.<域名>` 子域名,管理端与账户端共用一个登录页,
  登录后按角色进入各自界面
- **更新日志弹窗**——服务器更新后,账户再次登录会自动看到本版本的更新日志
- **事件可编排**——插件监听支持优先级、可取消传播、可改写事件参数
- **专属昵称插件**——观众给自己设一个昵称,之后所有涉及他的事件里都会用这个昵称
- 顺带修掉了一个**永不过期的账户一旦续期就变成限期**的缺陷

## ✨ 新增功能

### 登录与更新提示

- **统一登录入口**——管理端与账户端不再用不同子域名区分,
  同一个登录页按登录凭据决定进入哪个界面
- **更新日志弹窗**——服务器更新后账户再次登录自动弹出该版本日志,每个账户每个版本只弹一次;
  日志随部署包一同分发,无需联网

### 事件系统

插件的事件监听现在具备三项能力:

| 能力 | 用法 |
|------|------|
| 优先级 | `@event_handler(priority=N)`,值越大越先收到事件;不写则顺序与旧版完全一致 |
| 取消传播 | 用户内容类事件(弹幕 / 礼物 / 进入 / 关注 / 提问 / 跨房)可调用 `event.cancel()` 阻止继续传给后续插件 |
| 改写参数 | 事件的属性可直接赋值,改动对后续插件可见;`event.user.display_name` 可覆盖用户名 |

### 插件

- **专属昵称插件(新)**——观众发送 `昵称 xxx` 设置专属昵称,之后所有涉及他的事件中
  用户名都会被替换(欢迎、礼物感谢、签到等插件的文案自动跟随);`昵称` 查看、`重置昵称` 取消
- **插件配置分组**——配置页按「常用 / 文案 / 高级」折叠;未标注分组的插件渲染与之前完全一致
- **插件批量推送与默认插件**——面板可按插件或一次性把库版本推到各账户
  (自动跳过已是最新的);点亮星标设为默认插件后,新建账户会自动安装并启用
- **一键更新**——账户插件页一键把「副本落后于库」的插件全部更新到库版本
- **卸载数据分类**——卸载时可分别选择删除配置 / 插件数据 / 持久化数据,三项默认都不勾选
- **安装插件自动启用**——账户级偏好,默认关闭;开启后从插件库安装插件会随即启用
- **插件日志弹窗**——只显示插件相关日志(插件自身代码与框架的插件生命周期),
  可由插件库页的常驻入口、或插件卡上的「初始化失败」徽标打开

### 直播间与账户

- **跨房事件**——连麦时对方直播间的弹幕、大厅中送给其他麦的礼物现在有独立事件,
  监听本房弹幕 / 礼物的插件不会被对方直播间的事件打扰
- **直播间失联提示**——区分「未绑定」与「绑定了但加载失败」,后者给出提示并支持重试加载
- **设为永久**——账户概览按当前状态显示「设为永久」或「改为限时」

## 🐛 Bug 修复

- **永不过期的账户一续期就变成限期**——叠加续期把「永久」当成了「已过期」来起算,
  `永久 + N 天` 被算成了 `now + N 天`。修复后永久账户叠加续期会保持永久并给出提示;
  永久账户兑换授权码会被拒绝,且**不会消耗掉那个码**
- **面板上看不到插件失败的完整报错**——异常堆栈此前只写进日志文件,面板上只有一行摘要;
  现在完整堆栈会进入面板与插件日志弹窗
- **「删除配置文件」勾了不生效**——删除路径写成了目录而实际是文件,且失败被静默吞掉
- **插件库的「有更新日志」标记判断错误**
- **插件安装 / 更新流程的版本校验**——版本拒绝(409)曾被前端误当成「确认覆盖」信号,
  且确认后会绕过校验降级覆盖
- **插件配置分组点击无法展开**、**账户详情的插件页偶发白屏**
- **服务器页的插件数含义不对**——原为各账户已启用插件数之和,现为插件库中的插件总数

## 🔧 改进优化

- **账户卡片整卡可点**——删掉了作用完全重复的「管理」与「账户设置」两个按钮,
  改为点击卡片任意位置进入管理;键盘操作、中键新标签页打开也都支持
- **批量操作二次确认**——四处批量入口统一改为「预览 → 确认 → 执行」,
  确认弹窗可展开列出「将要影响哪些账户 / 插件」;无事可做时直接提示,不弹空确认框
- **插件初始化失败的处理**——移除「加载失败的插件」列表,
  改为插件卡上的红色「初始化失败」徽标 + 插件日志弹窗

## ⚠️ 升级注意

- **子域名入口取消**——原本用 `user.<域名>` 访问账户门户的方式不再区分,
  管理端与账户端统一使用同一个域名与登录页。若反向代理本来只转发了主域名,无需改动;
  若单独配了 `user.` 子域名,可以撤掉了
- **昵称指令不带方括号**——专属昵称插件的指令是 `昵称 xxx` / `昵称` / `重置昵称`,
  原来的 `[昵称 xxx]` 写法不再生效
- **「加载失败的插件」列表移除**——插件初始化失败改为在卡片上显示红色徽标,
  点击徽标查看插件日志;不再提供「重试 / 放弃」按钮,重新启用该插件即可重试
- **插件不再自带启停开关**——`timer_messages` 的 `enabled` 配置项已移除,
  插件的启用与停用统一由账户插件页的开关管理。
  若你此前把该配置设为关闭,请在账户插件页把该插件停用
- **账户插件副本需更新**——本次随发行更新了 `gift_thanks`(v1.3.2,跨房标注移到装饰框外),
  以及 `nickname` 与 `timer_messages`。各账户的副本不会自动跟随,
  请在账户插件页点「一键更新」或逐个点「更新」
