# 🚀 MisMiss v1.7.0 — 下载能停，筛选记得住

<div align="center">

**更新下载进度/停止 · 歌单分页与自定义指令 · 筛选持久化 · 启动与日志治理**

---

v1.7.0 集中解决「用起来不顺手」和「后台不干净」两类问题：更新下载卡住时可以停、
歌单太长不再发失败、切页回来筛选还在、停用 Bot 不再空转定时器；同时修掉
重复实例、重复回复、启动顺序和日志污染等一批线上反馈。

## ⬇️ 在线更新：进度与停止

- 更新下载改为 **异步流式下载**，每 0.5 秒写入已下载字节数、总大小和百分比；
- 前端进度条显示 `51% · 100 MB / 196 MB`，拿不到 `Content-Length` 时退化为动态进度条；
- 新增 `POST /api/update/cancel`：
  - 准备 / 下载阶段可随时 **停止更新**；
  - 停止后立即关闭连接、删除半截文件，终态为 `cancelled`；
  - 已进入通知 / 备份 / 解压 / 导入镜像阶段返回 409，避免留下半套部署；
- 下载读超时从 300 秒收紧到 60 秒，即使无人操作，卡死的下载也会自行失败；
- 修复更新日志「下载完成但页面一直转圈」的残留 `running` 状态。

## 🎵 歌单插件 1.1.1

- 歌单按 **`page_size` 分页**，默认 6 首/页；发「歌单 2」「歌单2」翻页；
- 分页会同时计算 `max_chars` 字数预算，**一页通常就是一条消息**，不会再出现
  「第 6 首被拆到第二条」；
- 只有单行本身超长时才按行硬拆，保证每条不超过上限；
- 指令名与别名可在面板自定义：`cmd` / `cmd_aliases`，改完立即生效；
- 页码行支持 `{page}` / `{total}` / `{cmd}` / `{next}` 占位符；
- 默认别名移除与点播插件冲突的「点歌单」，避免两个插件同时响应。

## 📊 直播间信息插件 1.1.0

- 「直播间」数据卡片新增 **👥在线人数**；
- 数据仍全部来自猫耳公开接口，接口没给该字段时按 `show_unknown` 规则处理。

## 🖥️ 面板体验

- **筛选持久化**：账户总览、日志页、插件库、账户插件页、定时消息页的搜索词与
  筛选条件写入 `sessionStorage`，进入详情再返回、侧栏切走再回来、刷新页面都不丢；
- **页码持久化**：账户总览恢复上次页码；页码在当前离线数据下不存在时自动回第 1 页；
  筛选条件变化仍回第 1 页；
- **过期标识**：`已过期停用` 改为 `已过期x天`，悬停显示精确到期时间；
- **默认时长**：创建账户默认 **3 天**（仍可填 -1 永久）；续期默认 **31 天**；
- 续期语义不变：已过期账户仍从「现在」起算，不会倒扣过期天数。

## 🛠️ 稳定性修复

- **切换 Cookie 后旧 Bot 继续发定时消息**：`create_bot` 先取消旧实例的定时器与消费者，
  再切换；旧实例的定时消息完整迁移到新 Bot；
- **停用 Bot 后定时器空转**：`enabled=False` 立即取消定时循环与消息消费者，清空积压队列；
  普通定时消息配置保留，重新启用时恢复；
- **一条指令回复两次**：
  - 插件激活/停用/重载按插件加锁，避免并发创建两个实例；
  - `PluginManager.shutdown_all()` 同时从 EventBus / CommandRouter / UI 路由注销；
  - 直播间 `join` 串行化，避免并发连出两条 WebSocket；
- **重启优先恢复开播中的直播间**：启动前探测各账户房间状态，按「开播中 → 其他 →
  已过期」排序；单次探测最多等 5 秒，失败按未开播处理；
- **日志治理**：
  - 每次进程启动截断当天的 `bot_*.log` / `error_*.log`，历史日期保留；
  - 删除每条消息发送、定时器每个 tick、广播逐账户跳过、插件逐个扫描等流水账日志；
  - 明确「debug 也不是流水账」的日志约定；
- **start.bat**：
  - 优先使用项目 `.venv` 的 Python，避免系统解释器缺 FastAPI 导致窗口一闪而过；
  - 修复清理端口时窗口标题 `MisMiss Web*` 误杀启动脚本自身的问题；
  - 增加 Python 依赖预检与更清晰的错误提示。
