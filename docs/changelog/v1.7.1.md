v1.7.1 是对 v1.7.0 的补丁：修正筛选条件只存在单个标签页、换标签就丢的问题；
同时修正直播间信息插件的在线人数来源，并恢复消息发送的 DEBUG 流水账。

## 🖥️ 筛选持久化修正

v1.7.0 的筛选条件写在 `sessionStorage`，它是**标签页级**存储：

- 在账户详情返回原标签页时能恢复；
- 新开标签页、换一个标签页打开面板时是空的；
- 关闭标签页后清空。

这会让用户以为「筛选保留没生效」。v1.7.1 改为：

- 默认写 **`localStorage`**，同一浏览器的新标签页、关闭后重开、重启浏览器都能恢复；
- 自动把 v1.7.0 留在 `sessionStorage` 的旧值迁移过来；
- `localStorage` 不可用时仍回退 `sessionStorage` / 内存；
- 账户总览、日志页、插件库、账户插件页、定时消息页的筛选与页码一并生效。

同时给 nginx 的 SPA 入口加 `Cache-Control: no-store`：升级后浏览器不会继续用旧的
`index.html` 加载旧 JS；`/assets/` 仍保持 immutable 长缓存。

## 📊 直播间信息插件 1.1.1

- 在线人数改为优先读取直播间 **WS `room:statistics`** 推送的
  `livestream.online_count`，与面板前端显示同源；
- REST 的 `statistics.online` 对非主播身份通常恒为 0，不再让它覆盖真实在线人数；
- WS 尚未推送时才回退 REST 值。

## 🪵 日志

- 恢复「发送消息 直播间/内容/优先级/剩余」DEBUG 流水账；
- 定时器停用跳过、广播逐账户跳过、插件重复扫描等无意义日志继续保持清理。

## ⚠️ 升级说明

- 已安装的 `room_info` 插件需要更新到 **1.1.1**；
- Docker 用户升级后如果页面仍是旧版，强制刷新一次即可；nginx 已对入口加 no-store；
- 本版本无破坏性配置变更。
